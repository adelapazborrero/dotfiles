# Firefox

## Custom CSS

1. Open `about:config`
2. Enable `toolkit.legacyUserProfileCustomizations.stylesheets`
3. Open `about:support` and go to your **Profile Directory**
4. Drop [CustomCSSforFx](https://github.com/Aris-t2/CustomCSSforFx/tree/master/current)
   into a `chrome` folder there (create it if it does not exist)
5. Restart Firefox
